# 网文站关联 + WebDAV 同步：调研与方案

> 2026-11-16 实测，本机出口网络。HTTP 状态码在同一台机器、同一 UA 下测得，隔天可能变。

## 一、阅微支持哪些网站

先给结论：**阅微没有「支持站点清单」这个东西**，所以照抄它的列表这条路不存在。理由如下（均为公开资料）：

| 事实 | 来源 |
|---|---|
| 阅微 = 枕冬科技（无锡），包名 `app.zhendong.reamicro`，最新 2.3.3（2026-10-30），定位是**本地 EPUB 阅读器** | 小米应用商店详情页 |
| 导入方式：设备存储 / WebDAV / 百度网盘 / 阿里云盘 / 115 网盘 / S3 兼容对象存储（Cloudflare R2、缤纷云） | 官网 + App Store 版本说明 |
| 官方关于「关联」只有一句：「提供标准的图书信息关联，以解决图书文件内信息不够准确」 | 官网描述 |
| 它**不带** Legado 那种书源生态；书源是社区 LSPosed 模块「阅微补全计划」补的，且该模块明确写「支持导入阅读/Legado 书源格式的在线源」 | modules.lsposed.org 模块页 |

也就是说，阅微的「关联」是**拿书名/文件内元数据去公共图书库匹配一条准确记录**（作者、封面、简介），不是按站点抓标签和评论。它的书评区是自己社区，不是抓豆瓣。

对我们的价值在交互设计（详情页一个「关联」入口，可改、可取消、可修封面），不在站点列表。真要列站点，得自己定。

## 二、我们的站点清单（实测）

| 站点 | HTTP | 能拿到 | 结论 |
|---|---|---|---|
| **豆瓣图书** | 200 | `j/subject_suggest` 返回 JSON：书名/作者/封面/年份；详情页可抓评分（实测 8.9）、作者 | **首选**，唯一现在就稳的 |
| 番茄小说 | 200（首页是真 HTML） | 书名/作者/封面/简介；搜索接口有签名，要逆向 | 第二优先 |
| 起点 | 202 | JS 探测墙，拿不到正文结构 | 第三，需浏览器渲染或放弃 |
| 优书网 | 000（DNS 不通） | — | 放弃 |
| 龙空 | 200 | 论坛形态，无结构化书籍接口 | 低优先 |
| 纵横 / 晋江 / 刺猬猫 | 200 | 未测接口 | 备用 |

**豆瓣那条接口有个坑**：不带 `Referer: https://book.douban.com/` 会返回 `[]`，带了才出数据。所以必须在 relay 里发请求，不能前端直连（前端改不了 Referer，且会被 CORS 拦）。

实测样例（`q=三体`）：

```json
[{"title":"三体","author_name":"刘慈欣","year":"2008",
  "pic":"https://img3.doubanio.com/view/subject/s/public/s2768378.jpg","id":"2567698"}]
```

**顺带解决 12 本「佚名」**：等这个适配器上线，按书名查豆瓣拿作者，比抠封面图 OCR 靠谱得多（见 `docs/decisions.md` 第 19 节）。

## 三、WebDAV 同步

目标：坚果云。存的不是书，是**书库索引 + 进度 + 书签**——500 本 × 15MB 传网盘既慢又没必要，书本身留在手机本地。

```
/书阁/
├── library.json          书籍索引（uuid/书名/作者/封面哈希/大小/指纹/最后修改）
├── progress.json         全部进度（uuid → cfi, percent, updatedAt）
└── bookmarks.json        全部书签
```

三件事要定：

1. **走中继，不走前端直连**。坚果云不返回 CORS 头，浏览器里 `fetch` 会被拦；`relay/core.mjs` 已经留了 `/api/dav/?to=<urlencoded>` 的反代骨架，PROPFIND/PUT/GET 都已在 CORS 白名单里。
2. **冲突按 `updatedAt` 逐条取新**，不做整文件覆盖。两台设备都读了同一本书、各自推进度，取时间晚的那条；时间相同取 `percent` 大的。
3. **删除留墓碑**。`{ "uuid": ..., "deletedAt": ... }` 而不是真删，否则 A 设备删一本书，B 设备同步时会把本地记录又「复活」回来。

不做：epub 本体同步、多账号、增量二进制传输。想做的时候再说，接口能扩。

## 四、落地顺序

| 步骤 | 内容 | 依赖 |
|---|---|---|
| 1 | relay 加 `douban` 适配器（search/detail），前端详情页加「关联」入口 | 现在就能做 |
| 2 | 用关联结果回填作者/封面，12 本佚名收尾 | 步骤 1 |
| 3 | 坚果云 WebDAV 三条 JSON 的上行下行 + 冲突合并 | 需要你给一个坚果云应用密码 |
| 4 | 番茄适配器，再评估起点 | 步骤 1 的适配器框架 |

步骤 3 的坚果云账号要你自己在「账户信息 → 安全选项 → 添加应用」生成应用密码，我不碰你的主密码。
